# Chemistry Fundamentals

This is the **floor** for the entire lithium project. By the end of this
folder you should be able to:

- Pick up any chemistry text — undergraduate or graduate — and read it
  without bouncing off the vocabulary.
- Parse a sentence like *"In the COLEX process, the equilibrium constant for
  Li-isotope exchange between aqueous LiOH and Li(Hg) yields a separation
  factor α ≈ 1.054 favoring Li-6 in the amalgam phase"* — every word, no
  hand-waving.
- Move into water-treatment and isotope-separation material with no friction.

You may have failed Chem 101 three times. **Capacity was never the issue.**
This time you're paying attention, you have a real reason to learn it, and the
material is going to come at you in the order it actually depends on itself.

## How to work each file

1. Read it through once with attention.
2. Close the file. Try to **explain it back** to someone (or to Claude).
3. Open `04-learning/knowledge-tracker.md` and update the symbols.
4. Only promote a concept from 🔴 → 🟡 when you can answer the self-check
   questions at the bottom of that file without peeking.
5. Only promote 🟡 → ✅ when you can teach the concept unprompted and predict
   at least one *consequence* of it that you weren't told.

## What's in each file

Every file follows the same shape so you know where to find what:

1. **Prerequisite check** — what to have absorbed before reading
2. **Rigorous statement** — the formal definition / principle (with units!)
3. **Plain-English unpacking** — what it actually means
4. **Concrete picture / analogy** — something you can see in your head
5. **Worked example or specific datum** — a calculation or anchoring number
6. **Common misconceptions** — what *not* to believe
7. **Connection to next file** — what loads next and why
8. **Self-check questions** — Socratic probes

A note on rigor: where there's a real number, you'll see the real number with
units (and CODATA values for fundamental constants). Where there's a
historical experiment, it's named so you can look it up. This is not
hand-waving territory.
